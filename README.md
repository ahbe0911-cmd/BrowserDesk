# BrowserDesk

BrowserDesk is a lightweight Windows 10/11 launcher for managing websites and opening them with the real browsers already installed on Windows.

## v0.1 features

- Chrome, Mozilla Firefox and Microsoft Edge detection
- Shows installed browser versions
- Quick URL launcher
- Persistent bookmarks
- A preferred browser can be saved for each bookmark
- Double-click a bookmark to open it
- Browser window can automatically occupy the left 50% of the working area
- BrowserDesk can stay in the right 50%
- Uses the browsers installed on Windows, so browser updates are automatically picked up
- GitHub Actions builds a self-contained Windows x64 package

## Build

Push to `main` or run the **Build BrowserDesk** workflow manually. Download the `BrowserDesk-win-x64` artifact from the completed Actions run.
